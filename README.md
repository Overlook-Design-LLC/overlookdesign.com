# overlookdesign.com

Static site for https://www.overlookdesign.com, served by GitHub Pages from `main`.

Plain HTML, no build step. Edit a page, commit, push — it's live in about a minute.

- `index.html` — home page (Joyner + Minder cards)
- `joyner/`, `minder/` — app pages with store links, plus `privacy`, `terms`, `support`
- `assets/site.css` — the one stylesheet (light + dark)
- `CNAME` — custom domain for Pages; don't delete it
